Settings move off the light bar and into their own window, and the bar stops interfering
with Cursor's menu-bar item.

**Settings are a window now.** Right-click the bar and it reveals its own controls — a close
button under each light, and a settings gear. The gear opens a normal window with General,
Lights, Colors, Audio, and About sections, in your system's light or dark appearance. The
sixteen controls that used to unfold out of the always-on-top strip are gone from it, so the
bar is lights again.

**Close a light by hand.** Every way a light disappeared before waited on evidence — a closed
window, a dead process, an archived conversation. The × beside a light drops it now. If the
session is really still running, its light comes back on its next event.

**The bar no longer closes Cursor's menu.** Reading Cursor's menu-bar item over the
Accessibility API cancels that menu if you have it open, and the bar was doing it every five
seconds for as long as an idle Cursor light existed — to decide something already decided.
It now reads only when the answer can change a light, and **Lights → Cursor pip → Hide**
stops the read altogether.

**Clicking the Cursor pip clears the notification.** On Cursor 3.15.6 opening a composer no
longer marks it read, so the pip kept coming back. The click now presses Cursor's own
"Clear All Notifications" after opening the agent.

**An orange light always means a session is waiting on you** — including a background agent
that stopped to ask a question.

macOS 13 or later (universal, Apple Silicon and Intel), or Windows 11 on x64.
